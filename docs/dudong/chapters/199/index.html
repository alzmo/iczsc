第五卷 · 后背

第一百九十九章 遗言

2026年10月24日约 3 分钟

秦渡松开压着雷枭的膝，身下的冰又响了一声。

水从裂缝里渗上来，浸过手掌。他向较硬的岸边挪，胸口贴着冰雪，左手仍被雷枭扯住。

“放手！”他喊。

雷枭没有答，身体忽然往下一沉。

冰碎了。

秦渡本能地抓紧那只手腕，自己也被往回拖了一截。冰水涌上来，衣袖瞬间湿透，肋侧的痛让他几乎喘不过气。

岸上，许知满在喊。

他咬着牙，另一只手向后抓，碰到岸边露出的草根和硬土。他终于稳住一点，回头看见雷枭半个身体已陷进破开的水面。

“借力！”秦渡说，“往这边！”

雷枭抬着头，喘息混着水声，手却没有依言抓住冰沿。秦渡不知道他是动不了，还是仍不肯照自己说的做。

风把两人的声音吹得很散。

那张曾在照片上看过无数次的脸，此刻近得让他能看见眉边的血。这个人带走过他，又带走了小满。那些年，那些孩子，都还没有得到一个交代。

秦渡想将他拉过来，手臂却一点点往下沉。

“小崽子。”雷枭忽然说。

秦渡低头看他。

“背走你的那个人……”

水碰到雷枭的下巴，他昂起头，话断了一下。

“后来又把你买回去。你还当他是好人？”

秦渡的手猛地收紧。

“谁？”

雷枭喘了一口气，脸上露出一个模糊的表情。

“就在你身边。”

秦渡还要问，冰沿又断开一块。雷枭身体下坠，手腕在湿透的绷带里滑动，秦渡往前探了一下，脚下的支点也随之松动。

“别往前了！”许知满的声音几乎劈开，“哥！”

他最后抓住的只剩一段散开的白布。

布从掌心里抽出来，雷枭的手没进水里。

秦渡伸出去的手悬着，什么也没抓到。

＊

水面翻涌，碎冰撞在一起。

秦渡向那片黑水喊了两声，没有回应。他伏在岸边找，想看见一只手、一个衣角，哪怕一点还在动的东西。

只有雪不断落下来。

身后传来拖动的声音。

许知满从车旁往这边挪，盖在腿上的毯子滑了半截。她撑着地面，脸色白得吓人，还在喊他上来。

秦渡猛地回头。

“别过来！”

她停住了，嘴唇哆嗦着，又叫了一声哥。

秦渡向后挪回硬实处，手里攥着那截湿白布。他将它收进衣袋，踉跄着回到她身边，把滑下去的毯子重新拢好。

许知满抓住他的手臂，抓得很紧。

“你也下去了……”

“我上来了。”

“我叫你，你不回头。”

她的声音碎了，眼泪顺着脸往下掉。秦渡贴近她，额头轻轻抵住她的额头，没有再说自己没事。

“对不起。”他说。

许知满摇头，只是不肯放手。

＊

手机还是接不通，电量已经很低。

秦渡将落水位置和两人的情况录好，试着再发一次。许知满裹在外套里看着河面，眼神没有焦点。

“他是不是……”

“没看见上来。得让人来找。”

她点了一下头，嘴唇仍抖着。

过了一会儿，她说，雷枭下桥时护过她的头，在车里也给她加过衣服。

秦渡听着，没有替那个人作解释。

“可我一直怕他。”她说，“刚才他拿枪对着阿依，我怕得都站不稳。”

“我知道。”

她忽然抬头看他。

“我不想看见谁掉下去。”

秦渡把她拢紧些。

“我也不想。”

她靠在他身前，过了好一会儿，才轻轻点头。

雷枭最后那句话，仍在秦渡耳边响。背走你的那个人，后来又把你买回去。

他想起一个烟味很重的背影，想起有人将他往背上颠了颠，怕他往下滑。又想起在南边见到那个老人时，对方递来的食物和一直没有说清的过去。

这些片段撞在一起，胸口像被撕开了一道口。

可雷枭的话，未必全是真的。甚至可能是最后还要留给他的一根刺。

秦渡垂下头，看见许知满放在外套边缘的手。

她的手指很冷，回应比刚才慢了。

他把那些片段压回去。现在不能想这个。

＊

河边没有能避风的地方。

秦渡检查身旁还能启动的车，将能用的干燥盖物重新包好，遮住许知满的头颈和身体。她伤着的脚不能随便挪，他放得很慢，一边问疼不疼。

“疼。”她说。

“我轻一点。”

她望着他，眼泪又下来了。

秦渡扶她坐稳，尽量保住身上的覆盖物。他看向来时的方向，车辙已有一半被新雪盖住，远处的树只剩模糊的影子。

他不知道救援离这里多远，也不能让她继续坐在河岸吹风。

手机上还留着一部分来路记录。秦渡看过，再将它贴身收好。

引擎响起来。

“抱住我。”他说，“我们往回走，找能挡风的地方。”

许知满将手臂绕到他身前。

“好。”

第一百九十六章 雪地摩托

2026年10月24日约 3 分钟

厂房后面，有人正在核查雪地摩托离开的方向。

秦渡跟到门边，看见雪里一道新辙，从旧棚旁绕出去，钻进了林子。风还没有把它盖平。

棚里剩着一辆车，钥匙挂在车头，旁边搁着头盔。刚才冲出来的人都往北边去了，这一处反而空着。

“他让你去，不等于你就能去。”陪同人员对秦渡说，“外围已经接到消息。”

秦渡望着那道车辙。

阿依刚才说，许知满出去时一直在喊。他不知道她穿了多少，能不能走，有没有受伤。她在照片里露出的那只手，瘦得让他不敢多看。

手机忽然响了。

是雷枭。

秦渡按下接听，打开外放。

风声里传来断断续续的声音：“小崽子，听见了？”

“让她说话。”

那边只有发动机的轰鸣。

“她冷。你要是走慢了……”

话没说完，通话断了。

陪同人员立刻将情况转报，示意秦渡留在身旁。周默从另一侧赶来，脚步踩在雪里，又深又重。

秦渡已经走向了棚子。

“秦渡！”

他听见了，脚步却没有停。十八年前那串越追越乱的脚印，仿佛忽然又铺在眼前。他知道有人正沿别的路去堵截，也知道自己这一走，会给后面的人添更多变数。

可他此刻只能想到，前面那辆车还在把她带远。

他戴上头盔，跨上雪地摩托。

周默赶到时，车已经发动。秦渡朝他喊：“往北，跟着新车辙。我手机开着！”

“别一个人追！”

风将后半句盖住。

他开出棚子，拐进林路。身后的喊声仍在，随后被引擎声压了下去。

＊

林子里的雪没有空地上那么厚，有些地方露着暗色的泥和旧冰。

秦渡盯着前车留下的痕迹。车身一颠，膝盖就像被什么尖锐的东西顶了一下。他不能像想象中那样一直加速，弯道上的横枝迫使他几次减慢，绕过倒木时险些滑出路边。

后方的联络接通过一阵。

他大声报出经过的岔口和能看见的标记，对方让他停在安全位置，不要再单独靠近持枪人。

“看见尾灯了。”秦渡说。

树林尽头，一点红光闪了一下，又被雪遮住。

他握紧车把，追过去。

电话里再传来声音时，已经听不清字。他没有关机，将手机收好，继续沿还看得见的痕迹走。遇上分岔，他停下来照了照，才重新启动。

这比他想的慢得多。

也比他想的冷。

胸前的旧棉袄硌着拉链。他记得自己在车里把它塞进去时，周默伸手替他压住了翘起的衣角。那动作很平常，像他们许多次出门前一样。

秦渡忽然希望，身后很快就能听见另一辆车的声音。

＊

许知满坐在雷枭身后，身上裹着另一件从棚里拿来的厚外衣，脸边绕着一条有油污味的旧围巾。

她的鞋没有穿好，一只在拉扯中掉了。雷枭将她绑在座上，免得她摔下去，绳子勒着腹部，每一次颠簸都疼得她喘不过气。

她试着挪动，却只换来更重的拉扯。

风从前面灌过来，大半被雷枭挡住。这个后背也很宽，可她贴在上面，只觉得恐惧。

她把脸偏开，免得闻见他衣服上的烟味。

“你要带我去哪儿？”

雷枭没有答。

车冲上一段坡，许知满的额头磕在他肩后。她眼前发黑，过了片刻才重新看清雪。

“你放我下来。”

“你哥来了。”他说。

她急忙回头，身体被绳子拽住，只能勉强扭过脸。

起初什么也看不见。过了一阵，一点白光从树林的缝隙里露出来，摇晃着，时近时远。

“哥！”

声音刚出口就被风吞了。

她仍喊，喊得喉咙发痛，却不知道那点光里究竟是谁。雷枭可能还在骗她，也可能是真的。她只想让后面的人听见这里有人，听见自己还活着。

＊

秦渡看见前车尾灯再次亮起时，树林已经稀了。

红光偏向一侧，慢下来。他收住速度，隔着雪幕，看见车停在一片开阔处。

再往前，地势低下去，黑色的水在白雪之间露出一道宽口。河岸旁立着界碑，风将碑上的积雪刮下来，又重新盖上。

雷枭站在车边。

他已经解开束缚，揪着许知满的外衣，把她拖下来。她一只脚踩到雪里，立刻向旁边歪了一下。

秦渡停下车。

手机仍没有接通。他将此处能认出的标记录下，发出的消息一直显示未完成。他没有再盯着屏幕，把它留在衣袋里，抬头看前方。

雷枭手里有枪。

秦渡站在车侧，没有再靠近。他摘下头盔，放在车座上，让雷枭看清自己的脸。

隔着漫天的雪，他终于看清那张脸。左侧的疤，深陷的眼窝，绷在手上的白布。十八年来无数个混乱的片段，在这一刻找到了活生生的主人。

雷枭也在看他。

“小崽子。”

他的声音被风扯散了一半。

“还是找来了。”

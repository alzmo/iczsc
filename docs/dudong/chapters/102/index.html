第一百零二章 接送

2026年10月23日约 3 分钟

车门一响，许知满便拉着母亲往里退。

来叫人的男人挡住了台阶下方，另一个人从车里下来，径直冲向门厅。秦渡侧身拦住他，肩膀撞上了门框。周默赶过来，护住许秀兰，叫门内的人报警。

许知满离门只剩一步。

身后有人抓住她背包的肩带，猛地一扯。她被带得踉跄，膝盖磕在台阶边，包带勒住肩膀。她松开那边胳膊，让包从肩上滑脱，回头就喊：“报警！有人拉我！”

抓她的人丢开包，又来扯她手臂。

许知满死死扶住门把，手背擦在金属边上，一阵火辣。她挣不开，便低头咬住那只伸到脸前的手。对方骂了一声，松了力，她趁机向门里挪了半步。

第三个男人也从车上下来，绕过同伴，伸手攥住她衣袖。

“别动！”

她没听。

外套口袋里有一支笔，是昨天写完材料顺手放进去的。她摸到笔杆，胡乱攥住，朝抓着自己的手扎过去。对方缩手时，秦渡已经将先前那人推离门框，挡在她与车之间。

有人抡起一根短棍。

秦渡来不及完全避开，抬臂挡了一下，闷响落在袖口上。他借着对方扑近的力，把人挤向台阶边，抓住持棍的手腕，压到栏杆上。

棍子掉了。

许知满退进门内，周默将母女护到一侧，没有追出去。门厅的工作人员正对着电话报地址，门外已有路人停下，大声喊着“别跑”。

白色面包车的发动机猛地轰起来。

那个被她咬伤手的人转身扑向侧门。车已经往前动了，他仍扒住门框，几乎被拖着带出去。秦渡将被压住的持棍者交给赶来协助的人看住，回身拦住另一个想跑的人。

车拐出路口，留下两个没能上车的人。

秦渡没有追。他和赶来帮忙的人守在原处，防止两人继续伤人，直到警员到场。周默将自己拍到的车牌和逃离方向提供出去，留下可联系的目击者信息。

许知满坐在门内的椅子上，手里仍攥着那支笔。

许秀兰蹲不了，便弯着腰一遍遍叫她的名字。她听得见，也想回答，可喉咙像堵住了，只能点头。

秦渡走到她面前，先看了眼母亲，又蹲下来。

“小满，人已经离你远了。”

她的手指白得没有血色。

“笔先放下，好不好？”

她看着他，指尖动了一下，没松开。

秦渡没有硬掰，只把手掌摊在旁边，等着她。过了一会儿，她终于把笔搁到工作人员拿来的干净托盘里，连同掉下的背包，一起留待核查。

掌心张开的那一刻，她忽然想起一只很小的手。

也是冬天，也是有人蹲在她面前，把她攥紧的手一点点拢住。那人往她手里放过一个硬东西，凉得她缩了一下，随后又让她握好。

画面短得像眨眼。她还想抓住，已经散了。

“哥。”

秦渡抬头。

“我好像又想起来一点。你以前给过我什么东西，让我攥着……”

他说话放得很轻：“铜扣？”

许知满看着自己空下来的手心。

“可能是。我看不清。”

“先不急。”

许秀兰的手落在她肩上。那颗扣子还在收好的小盒子里，母女都知道。此刻谁也没有要她把这一小片记忆讲成一个完整的故事。

秦渡看见她膝盖上的血，询问她哪里还疼。许知满活动了一下手指，说胳膊被拽得痛，头没有撞到，站起来时膝盖疼得厉害。

救护人员到场后替她作了初步检查，安排去医院处理。秦渡袖口下的前臂也肿起一片，周默让他一并检查，别只顾着别人。

许秀兰抓着女儿的手，眼睛红得厉害。

“我陪着。”

“您慢一点。”许知满这才找回自己的声音，“妈，您别急。”

原定接送的司机一直等在旁边，没有催他们上路。周默联系省医院的预约方，说明突发情况，先取消这一程，后续怎样调整等医生评估再说。

车门关上以前，许知满回头看了一眼门厅。

那只掉落的背包还在，拉链裂开，纸巾和一个钥匙扣散在台阶上。早上她以为自己已经很小心了，确实没有跟陌生人走，也没有把母亲交给那辆车。可别人伸手来拉的时候，还是那么快。

秦渡坐在她旁边，手臂垫在外套上。

“是不是很疼？”她问。

“有点。”

许知满吸了吸鼻子。

“那等会儿别说没事。”

秦渡看了她一眼，点头。

“你也是。”

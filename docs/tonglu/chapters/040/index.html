第四十章 下一堂的灯

2026年10月29日约 7 分钟

周三上午，陈野重新走进小训练室。

靠墙那排器材没有挪，镜子里仍旧照着门后那一截窄窄的通道。他把前天画的图铺到垫子上，蹲下来，将原来标着等候的位置往外移了一点。

韩教练拿着两杯豆浆进来。

“昨天的事，我听说了。”

“宣传更正了，林悦的两百元也退到了。”

“我是说那间屋子。”

陈野接过豆浆，没喝。杯子很热，隔着纸套仍能暖到手心。他想起那面没有拼缝的长镜，想起自己站到正中间，抬臂时不用先瞄一眼旁边有没有人。

“确实好。”他说。

韩教练在旁边坐下，没接一句这里也不差。

窗外有搬货的声音。楼下那家店每天这时候补货，铁轮碾过接缝，响一下，又响一下。陈野低头把图上的一条线擦掉，擦得太急，纸上起了毛。

“我当时真想过，签了以后把课带好，前面的事是不是也就能补上。”

“能不能？”

“有人按那张宣传交了钱，等的是上面的东西。不是等我以后慢慢解释。”

他停了停，笑得不太痛快。

“可把屋子让掉，还是心疼。”

“心疼就心疼。”韩教练把吸管插进杯口，“别为了一件事做对，就非得说自己一点也不想要。”

陈野终于喝了一口。豆浆有些烫，他皱着脸咽下去，韩教练看得笑了。

两个人在垫子上坐了一会儿，才重新谈课。

这里给不出他在新场地设想的全部时段，也没有单独挂他名字的门面。现有课程已经排在那里，不能为了一个新主意，把别人的预约挪来挪去。陈野将自己能固定留下的两个晚上圈出来，韩教练把馆里的安排放到旁边，两个人找到重合的地方。

周二、周四，晚七点半到八点半。

这周从周四开始。

周三空出的一段只能临时用；这两个晚上则能固定下来。原有练习按时结束，他们换场，先试四周。韩教练同馆里商定了排课和报酬，今天拿来让陈野自己看。

陈野在纸上写下名字，写到第二个字时，笔忽然没墨了。

他用力划了两下。

韩教练递来另一支：“没那么难。换支笔。”

陈野接过来，笑着把字写完。

中午，陈野把定下的时段分别告诉陆峥和许成安。四海下周还有小件运输要排，许成安听完，便从那两个晚上的候选人里划掉了他。

“你不是少了一份活。”许成安在电话里说，“是有自己的活了。”

陈野靠在窗边，半天才应了一声。

陆峥回得晚些，问周四散课以后有没有空，一起吃饭。陈野答应了，将手机收起来，又看了一遍自己刚刚签好的排课。

周四傍晚，雨停得晚。

七点刚过，陈野到门口时，看见周鸣正在楼下甩伞。伞骨卡住，合到一半又弹开，淋了他一鞋水。他气得想把伞扔进桶里，又拿回来，弯腰一根一根收好。

“今天店里不忙？”陈野问。

“忙。跟人换了班。”

周鸣抬起头，又赶紧解释：“不是专门为了你。我本来就有课没上完，放着也是放着。”

“知道。先擦擦鞋，别急。”

他没有帮周鸣把那句话说得更好听。两人上楼时，小余已经在更衣室外等着，手里抱着一双干鞋。看见周鸣，年轻人往旁边让了半步，问今天还能不能帮他看脚步。

“你别每次都找我，我还得练自己的。”

“那轮着来。”

周鸣想了想，点头。

七点二十，预约的另外两名学员也到了。一位是馆里的熟面孔，另一位是林悦。她昨天自己打电话问过，今天仍在前台又确认了一遍。陈野带她看小室，给她看今天要练的内容，没有问她是不是因为前天的事才来。

林悦绕了一圈，问这里是不是一直这么小。

“这四周就在这里。”

“后面呢？”

“后面还没定。定了先告诉你。”

她把背包放到凳上。

“那我先上今天的。”

女学员已经换好鞋，站在门边看课表。她问周二是不是也由陈野带，听到肯定的回答，又追问四周里会不会临时换时间。

“我这边按这个排。真有变化，会提前跟你们商量，不是到了楼下才说。”

“那就好。我得跟家里的人轮着接孩子。”

她说完，才察觉自己解释得太多，笑了一下。

陈野却问她，晚七点半会不会太赶。

“刚好。再早半小时我就来不了。”

他这才知道，自己和韩教练在纸上挪了好一阵的半小时，在别人那里，接着一所学校、一趟公交和另一人的下班时间。不是多排一个格子，就会多出一个肯来的人。

女学员将手机收进包里，走到周鸣旁边，问他今天是不是也换了班。两人聊起各自赶路的地方，原本陌生的小室里，先有了几声寻常的笑。

陈野领林悦去前台办当次手续，回来的时候，韩教练正在搬走最后一只备用沙袋。陈野伸手搭了一把，两人把它放好，重新看了一遍空出的地方。

小余从门边探头：“教练，今天练不练那个转身？”

“先把站稳练明白。”

“你上次也这么说。”

“你上次站稳了？”

小余闭上嘴，周鸣笑出了声。

七点半，陈野合上门，没有反锁。外面的说话声低了一些，四个人站在他面前，身后是还带着水痕的背包和折伞。

陈野问过每个人今天的状态，带他们开始热身。昨晚想好的开场白，一句也没用上。

人数比主厅少，沉默却比他预想的更重。

林悦总往后看，像怕自己站错；女学员很认真地学他的姿势，肩膀却越抬越高。陈野走到侧面，把原本背熟的讲法放下，自己先站成他们的样子，再缓缓改回来。

“别一起改。今天先找你能站住的位置。”

他把动作拆小，没有把声音喊得更大。

十几分钟后，屋里终于不只有他的声音。有人问脚跟为什么总想抬，另一个人说自己一紧张就憋气。周鸣本来想插一句自己的经验，看见陈野正在听，便把话留到轮换时再说。

第二轮，陈野换了一个题目。

他不再先做完整示范，而是请每个人说一件自己还没弄懂的事。女学员问，听到换边以后，为什么脑子里明白，手总慢半拍。小余认真想了一会儿，说自己以前是偷偷先猜下一下。

“所以你有时候快得不对。”周鸣说。

年轻人有点不好意思，却没反驳。

陈野请小余先做一次，这回不许猜。小余全神贯注，反而没有平时漂亮，做完自己先笑了。剩下的人看着他，也敢把动作放慢一些，不忙着装成已经学会。

林悦一直没有开口。

陈野问到她，她只说都行。轮到实际练，手套刚碰到靶便缩回来，好像碰了别人的东西。陈野收下手靶，站到她旁边，问她是不是不想做这部分。

“我不知道能不能用力。”

“可以从轻的试。我拿着，你看我。”

他没往前递靶催，先等对方把问题说完。

林悦低声说，来之前想了好几回，以为自己一打就是满脸凶相。真站在这里，却不知道该冲谁发怒。

陈野怔了一下。

他教过许多次握拳，却从没把这个问题写进自己的课表。他看着面前那双连指节都不肯收紧的手，忽然明白，新人不说话，并不一定因为害怕出错。也许自己觉得最寻常的动作，对别人已经很陌生。

“不用找谁生气。”他说，“这里不是欠你一拳的人。今天也不比声音。”

他用靶沿轻轻碰了碰自己的另一只手，示意一个简单的方向，随后站回去。

她试了一下，仍轻。第二次比第一次清楚，做完抬眼看他，像在确认这样也可以。

陈野点头。

他没有喊其他人来看这个进步。周鸣在旁边练自己的，小余重新试着等提示，女学员也不再一着急就跟着别人换手。

四种快慢，终于留在了同一间屋里。

八点半，下课。

林悦摘掉手套，掌心全是汗。她在前台问下周同一天有没有位置。陈野路过时，听见她对工作人员说，先约一堂，时间确定能来。

陈野回去收器材，第一次觉得这间小室比开始时大。

外面的课还在继续。韩教练带着另一组人经过，朝他扬了一下手，没停下来听汇报。陈野擦净靶面，将那副绑带松的单独放开，写了张纸压在上面，明天再修。

手机响了。

陆峥发来一张店门的照片，说他们已经到了，不急，桌上还没上热菜。

陈野将课程记录补完，最后检查了一遍，拿包下楼。雨停了，路边落着一层细小的叶子。他踩过水洼时，鞋尖沾了泥，没回去擦，往前又走了两步，才忍不住笑出来。

没人把钥匙交给他。

可这一晚，屋子确实是他自己带着人用起来的。

饭店不远。陈野推门，看见许成安和向南都在，桌上摆着四只杯子，陆峥正在同老板说等人齐了再炒。

“你们怎么一块儿来了？”

“我欠你一顿饭。”许成安拍拍旁边的椅子，“这顿先记你账上，欠的我下回还。”

陈野把包放下：“算盘打得够响。”

向南将菜单递给他，自己那页已经圈了两个菜，又很认真地解释，一个是大家吃，一个是他想吃的，不用都点。

陈野全留下了，添一份汤。

许成安问今天多少人。

“四个。”

“够你教？”

“够。我差点没听明白其中一个人在问什么。”

他说起林悦的问题，没说姓名。许成安听着，慢慢放下茶杯。

“所以她后来肯试了？”

“肯了。也没非得冲谁生气。”

“那挺好。”许成安说，“有时候我就想下班以后，脑子里能换点别的。”

“你要来，先问前台时间。”陈野道。

“我说想换脑子，你马上给我找活。”

向南听得笑出了声。

菜正好端上来，话被一阵热气岔开。向南先给每个人盛汤，盛到自己时只剩半碗，陈野把自己的碗推回去，叫他重新匀，别每次都把最后那点留给自己。

年轻人低头拿勺，许成安没有替他说懂事。

陆峥从包里取出一张卷着的课表，放到陈野手边。那是陈野早上请他顺路打印的，纸边用夹子夹着，没有装框。

陈野展开，看了一遍时间，又看自己的名字。

“这儿字号小了。”

“现在提，来得及改。”陆峥说。

“明天我自己印。你今天休息。”

“我也会用打印机。”向南忽然插话。

三个人都看向他。他没躲，认真地说自己不是来抢活，只是刚才听他们说了半天，觉得有的地方，也许自己能搭把手。

陈野把纸递给他。

“行。明天你有空，教我把这两行改大，别替我全做了。”

向南接过去，眼睛亮了一下。

许成安往后一靠，端起茶杯：“那就祝陈教练第一堂固定班，顺顺当当。”

“也不是全顺。”陈野道。

“那就祝下回还有不一样的问题，你还肯教。”

几只杯子碰到一起，杯沿发出一声轻响。店里很吵，隔壁桌正在争谁付钱，没有谁为这句祝愿安静下来。

饭后陈野去结账，回来的路上被陆峥叫住。陆峥站在门边，手里拿着他的包，没有问赚了多少，也没说等规模大了以后会怎样。

“今天还想那间大屋子吗？”

陈野望向街对面，过了一会儿才答。

“想。不过今天这四个人，我记得更清楚。”

陆峥将包递过去。

陈野接到手，没有立刻背，反而腾出一只手，轻轻碰了碰陆峥的肩。

“你周一听我讲完，我一直想谢你。”

“你给我留了座位。”

“那以后也留。”

许成安和向南从后面出来，叫他们快走，车停得远。陈野把卷起的课表交给向南，自己替陆峥推开那扇有些沉的玻璃门。

街风钻进来，带着雨后凉意。

那间更大的训练室还在马路对面，明天也许会挂上别人的名字。这里的下一堂课，却已经有人约好时间，等着他去开门。
